# Site editorial rules

- Owner instruction, 22 October 2026: never use the Unicode U+2013 or U+2014 punctuation characters in any website text, blog, title, description, source label, draft, review copy or administration interface.
- Use ordinary punctuation or an ASCII hyphen instead. Apply the same rule to CMS content and future article drafts.
- Run npm run check:content-style and npm run build before publishing.
- Keep new medical information pending physician review. A punctuation-only correction does not grant medical approval to a draft.
- Preserve unrelated work. Never force-push or rewrite published Git history in this Lovable-connected repository.
